## ⚡ Features
- 📜 **Passive OSINT:** Leverages Certificate Transparency (crt.sh) logs for stealth enumeration.
- 🚀 **Active Bruteforce:** High-speed DNS resolution with multi-threading.
- 🎯 **Accurate DNS Resolution:** Extracts live `A` records and IP mappings.
- 🎨 **Modern CLI Visualizer:** Color-coded status updates.
